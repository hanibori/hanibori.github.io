# 운세도사 — 무료 사주풀이 정적 웹사이트

생년월일(양력/음력)과 태어난 시간을 넣으면 **사주팔자(년주·월주·일주·시주)**, **오행 비율**, **신강/신약**, **용신·기신**, **대운(10년 흐름)**, **2027 정미년 세운**을 계산하고, 이를 겹쳐 읽은 **7개 항목 심층 리포트(약 6,000자)** 를 만들어 주는 정적 웹앱입니다.
서버·데이터베이스·빌드 과정이 없어 GitHub Pages나 Cloudflare Pages에 폴더째 올리면 바로 동작합니다.

├── js/lunar-data.js      음력↔양력 변환 테이블 (1900~2035, 한국천문연구원 데이터)

## 로컬에서 보기

`index.html`을 브라우저로 열면 됩니다. 폰트(Google Fonts)를 불러오므로 인터넷이 필요하고, 그 외 기능은 모두 로컬에서 동작합니다.

## 배포

현재 배포 주소: **https://hanibori.github.io/unsedosa/** (저장소 `hanibori/unsedosa`, 공개, `main` 브랜치 루트)

1. 다른 곳에 배포할 때는 `sitemap.xml`(6곳), `robots.txt`(`Sitemap:`), 각 페이지 `<meta property="og:image">` 의 `https://hanibori.github.io/unsedosa/` 부분을 새 주소로 바꿉니다.
2. GitHub 저장소 Settings → Pages → Branch: `main` / 폴더: `/ (root)` 로 지정하면 `https://아이디.github.io/저장소명/` 에서 열립니다.
4. 애드센스 승인 후 `index.html` 상단의 주석 처리된 AdSense 스크립트를 실제 코드로 바꿉니다. (승인 전에는 광고 스크립트를 넣지 않습니다.)

## 계산 방식 요약

| 항목 | 방식 |
|---|---|
| 년주 | 입춘(태양 황경 315°) 시각 기준 |
| 월주 | 24절기 절입 시각(태양 황경) 기준 |
| 일주 | 율리우스일 기반 60일 순환, 자정(00:00) 기준 |
| 시주 | 2시간 단위 12시, 23:00~00:59 자시 |
| 음력 | 한국천문연구원 음양력 데이터(1900~2035) |
| 표준시 | 1954-03-21~1961-08-09는 UTC+8:30 적용 |
| 오행 | 여덟 글자 각 1개씩(시주 없으면 6개) 비율 |
| 십신 | 일간 기준 관계(비견~정인) |
| 신강/신약 | 자리별 가중치(월지 1.9배)로 세력을 계산해 판정 |
| 용신/기신 | 신강·신약 + 오행 분포 + 조후(겨울→화, 여름→수)로 도출 |
| 대운 | 년간 음양·성별로 순행/역행, 절입(節)까지 날수 ÷ 3 = 대운수, 월주에서 10년씩 |

절기 시각은 태양 겉보기 황경 계산으로 구하며, 실제 절기 시각과 1~2분 차이가 날 수 있습니다.

## 테스트

```bash
node saju-site/test/engine-test.js
```

검증 항목 (모두 통과):
- 2026-11-26 → 병오년 · 기해월 · 갑진일 (외부 만세력 3곳과 일치 확인)
- 24절기: 소설 11-22 / 대설 12-07 / 동지 12-22 (한국천문연구원 발표값과 1~2분 이내)
- 입춘 경계(2/3 → 을사년, 2/5 → 병오년), 축월 판정
- 음력 변환: 2026 설날 2/17, 2025 윤6월 7/25, 없는 날짜 거부
- 십신 5종, 궁합 점수 범위, 60갑자 60개
- 대운: 순행/역행(양남음녀), 대운수, 10년 간격, 현재·다음 대운
- 용신/기신: 오행 관계(생·극) 및 십신 그룹 일치, 조후 보정
- 심층 리포트: 7개 항목 · 항목당 400자 이상 · 5문단 이상 · placeholder 없음 (여러 생년월일 교차 검증)

## 심층 리포트 구성

결과 화면은 다음 7개 항목을 아코디언으로 보여줍니다. 각 항목은 도사 말풍선(9개 탭)과 연동되어 핵심을 다시 짚어줍니다.

1. 핵심 총평과 인생 키워드
2. 성격과 기질 심층 분석 (겉모습/속마음, 무기, 스트레스, 약점)
3. 재물운과 돈 모으는 전략 (유입 구조, 새는 구멍, 투자 성향, 타이밍)
4. 직업운·적성·성공 환경 (적성 5종, 조직형/독립형, 피해야 할 환경)
5. 연애운·배우자운·대인관계 (배우자상, 귀인 띠, 갈등 포인트)
6. 10년 대운 흐름과 2027 정미년 (상·하반기 + 봄·여름·가을·겨울)
7. 개운법 — 용신 채우기 (색·방향·음식·습관·회피 패턴)

## 참고

- 결과 카드 저장(`save-card`)은 캔버스에 캐릭터를 그리기 때문에 **http(s)로 열었을 때** 캐릭터가 포함됩니다.
  `file://`로 열면 보안 정책상 캐릭터만 빠지고 카드는 정상 저장됩니다.
- 접속 기록·입력값은 서버로 가지 않습니다. 마지막 입력값만 브라우저 localStorage에 남습니다.
