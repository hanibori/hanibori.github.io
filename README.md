# 운세도사 — 무료 사주풀이 정적 웹앱

생년월일(양력/음력)과 태어난 시간을 넣으면 **사주팔자(년주·월주·일주·시주)**, **오행 비율**, **신강/신약**, **용신·기신**, **대운(10년 흐름)**, **2027 정미년 세운**을 계산하고, 이를 겹쳐 읽은 **7개 항목 심층 리포트(약 6,000자)** 를 만들어 주는 정적 웹앱입니다.
두 사람의 사주를 겹쳐 읽는 **심층 궁합 리포트(7장 · 4,500~6,000자)** 와 **2027 정미년 심층 신년 리포트(6장 · 5,000자 이상, 12개월 캘린더 포함)** 도 같은 방식으로 조합합니다.
서버·데이터베이스·빌드 과정이 없어 GitHub Pages나 Cloudflare Pages에 폴더째 올리면 바로 동작합니다.

화면은 **모바일 앱형 세로 피드**입니다. 최대 460~480px 중앙 정렬, 상단 고정 헤더 + 가로 스크롤 카테고리 칩 + 하단 고정 탭바(홈·정통사주·궁합·2027운세·가이드), 테마별 사주 카드 피드로 구성됩니다.

## 캐릭터 매핑

| 캐릭터 | 파일 | 쓰이는 곳 |
|---|---|---|
| 꽃미남 도령 | `assets/char-doryeong.webp` | 홈 히어로, 정통·총운 테마(카드·결과 무대) |
| 우아한 선녀 | `assets/char-seonnyeo.webp` | 연애·솔로 테마, `compatibility.html` |
| 시크한 역술가 | `assets/char-chic.webp` | 재물·직업·팩폭·성격·신년 테마, `newyear-2027.html` |

작은 아바타(컷 HUD 23px, 카드 말풍선 34~54px)는 `*-face.webp` 얼굴 크롭을 씁니다. 결과 컷은 캐릭터를 3:4 프레임 아래쪽에 앉히고 좌우·위 가장자리를 `mask`로 배경에 녹입니다. 컷마다 `--h`(머리 크기)·`--x`(좌우)·`--fx`(반전)와 배경 팔레트(`data-mood`)가 바뀌어 카메라가 움직이는 것처럼 보입니다. 배경은 달빛 글로우 + 빛살 + 지평선 안개 + 스크린톤으로 만든 웹툰 톤입니다.

- 카드를 누르면 **저장된 생년월일(localStorage `saju-profile`)로 원클릭** 결과가 열립니다. 저장된 정보가 없으면 입력 카드로 안내하고, 입력을 마치면 선택했던 테마로 바로 풀립니다.
- 결과 화면은 테마에 맞춰 심층 리포트 7개 항목의 **순서를 바꾸고, 대화 스테이지의 12컷 순서도 같은 순서로 바뀝니다**. 전체 리포트(약 6천 자)는 `전체 리포트 한눈에 보기`로 그대로 유지됩니다.
- 공유·뒤로가기용 주소는 `index.html#theme-<테마키>` 형식입니다. (예: `#theme-money-main`)
- 글꼴·문구·디자인은 타이트사주(sajutight.me)의 구조만 참고하고 운세도사 브랜드(도령·선녀·역술가 캐릭터와 골드/잉크)로 재해석했습니다. 복제한 요소는 없습니다.

## 로컬에서 보기

`index.html`을 브라우저로 열면 됩니다. 폰트(Google Fonts)를 불러오므로 인터넷이 필요하고, 그 외 기능은 모두 로컬에서 동작합니다.
`file://`로 열면 localStorage가 막히는 브라우저가 있으니, 로컬 서버(`python3 -m http.server`)로 확인하는 편이 정확합니다.

## 계산 방식 요약

| 항목 | 방식 |
|---|---|
| 년주 | 입춘(태양 황경 315°) 시각 기준 |
| 월주 | 24절기 절입 시각(태양 황경) 기준 |

| 시주 | 2시간 단위 12시, 23:00~00:59 자시 |

| 표준시 | 1954-03-21~1961-08-09는 UTC+8:30 적용 |

| 십신 | 일간 기준 관계(비견~정인) |

## 심층 리포트 구성

결과 화면은 **웹툰 한 컷 스테이지**로 시작합니다. 3:4 세로 컷 안에 캐릭터가 서고, 그 위로 만화 말풍선 두 개가 꼬리를 캐릭터 쪽으로 두고 떠 있습니다. 말풍선은 컷의 안전 영역(캐릭터 얼굴 위)을 넘지 않게 글자 크기를 스스로 줄이고, 컷마다 샷(기본·중간·클로즈업)·좌우 구도·배경 톤·꼬리 방향이 바뀝니다. 좌상단 진행 배지(`3 / 12`)와 상단 진행 바가 채워지고, 컷이나 `다음 컷 →`를 누르면 다음 컷, 좌우 스와이프·`‹` 버튼으로 이전 컷을 봅니다.

- 컷 아래 선택지 버튼은 사용자가 직접 건네는 말입니다. `다음 컷 →`으로 순서대로 듣거나, `내 재물운부터 물어볼래`·`오행은 어떻게 돼?`처럼 원하는 항목으로 건너뜁니다. 고른 말은 컷 아래 노란 말풍선으로 한 번 뜨고, 캐릭터가 그 자리부터 이어서 답합니다.
- 마지막 컷에서는 `결과 카드로 저장` · `친구한테 공유` · `다른 테마도 들어보기`가 이어집니다.
- `전체 리포트 한눈에 보기`를 누르면 심층 리포트 7개 항목(아코디언)이 펼쳐집니다. 검색·애드센스용 본문도 이 안에 그대로 있습니다.

`compatibility.html`과 `newyear-2027.html`도 같은 웹툰 컷 스테이지를 씁니다. 궁합은 **선녀 도사(궁합 · 인연)** 가 두 사람의 일주·점수·설렘·속마음·오행·살림·갈등·비결·2027 흐름을 10컷으로 풀고, 2027은 **시크 역술가(2027 정미년)** 가 총운·상반기·하반기·재물·연애·건강·월별·개운을 10컷으로 풉니다. 점수 카드는 컷 아래에 바로 보이고, `전체 리포트 한눈에 보기`를 누르면 궁합 심층 리포트 7장과 2027 심층 리포트 6장 + 12개월 캘린더가 펼쳐집니다.

심층 리포트는 다음 7개 항목으로 구성됩니다.

1. 핵심 총평과 인생 키워드
2. 성격과 기질 심층 분석 (겉모습/속마음, 무기, 스트레스, 약점)
3. 재물운과 돈 모으는 전략 (유입 구조, 새는 구멍, 투자 성향, 타이밍)
4. 직업운·적성·성공 환경 (적성 5종, 조직형/독립형, 피해야 할 환경)
5. 연애운·배우자운·대인관계 (배우자상, 귀인 띠, 갈등 포인트)
6. 10년 대운 흐름과 2027 정미년 (상·하반기 + 봄·여름·가을·겨울)
7. 개운법 — 용신 채우기 (색·방향·음식·습관·회피 패턴)

## 참고

- 결과 카드 저장(`save-card`)은 캔버스에 캐릭터를 그리기 때문에 **http(s)로 열었을 때** 캐릭터가 포함됩니다.
  `file://`로 열면 보안 정책상 캐릭터만 빠지고 카드는 정상 저장됩니다.
- 접속 기록·입력값은 서버로 가지 않습니다. 마지막 입력값만 브라우저 localStorage(`saju-profile`)에 남습니다.
